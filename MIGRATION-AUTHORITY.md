## Canonical rule

The code under `packages/engine/` is the shared geometry/export authority for this repository.
Web and desktop interfaces must consume the shared packages rather than forking geometry logic.

## UI rule

The primary studio must remain ribbon-first and visually calm:
- automatic event intelligence on top
- direct terrain material colours in the second ribbon
- quick adjustments on the left
- live / production view in the centre
- engineering depth hidden in the Advanced drawer

New features must preserve this orientation unless a deliberate design review changes it.
